# 📱 Гайд по деплою на Amvera Cloud через веб-интерфейс

## Требования

- Python 3.10+
- Telegram токен бота
- Ваш Telegram user ID (OWNER_ID)

## Шаги деплоя на Amvera Cloud

### 1️⃣ Подготовка файлов

Скачайте все файлы из репозитория:
- `bot.py`
- `requirements.txt`
- `Procfile`
- `runtime.txt`
- `.env.example`

Создайте `.env` файл на основе `.env.example` и заполните переменные (опционально для локального тестирования).

### 2️⃣ Вход в Amvera Cloud

1. Перейдите на [amvera.io](https://amvera.io)
2. Войдите в аккаунт или зарегистрируйтесь
3. Нажмите **"Создать новое приложение"**

### 3️⃣ Выбор способа загрузки

В окне создания приложения выберите **"Загрузить файлы"** (не Git)

### 4️⃣ Загрузка файлов

Загрузите следующие файлы в указанном порядке:
1. `bot.py` — основной файл бота
2. `requirements.txt` — зависимости
3. `Procfile` — конфигурация запуска
4. `runtime.txt` — версия Python

⚠️ **Важно:** Все файлы должны быть в корневой директории (без подпапок)

### 5️⃣ Настройка переменных окружения

После загрузки файлов в интерфейсе Amvera перейдите в **"Переменные окружения"** и добавьте:

| Переменная | Значение | Обязательна |
|-----------|---------|-----------|
| `BOT_TOKEN` | Ваш токен бота от @BotFather | ✅ Да |
| `OWNER_ID` | Ваш Telegram user ID | ✅ Да |
| `WEBHOOK_URL` | URL вашего приложения на Amvera (например, `https://my-app.amvera.io`) | ⚠️ Опционально* |
| `WEBHOOK_PATH` | `/webhook` | ❌ Нет (по умолчанию) |
| `PORT` | `8080` | ❌ Нет (по умолчанию) |

*Если `WEBHOOK_URL` не установлен, бот будет работать в режиме **polling** (периодически опрашивает Telegram). Это медленнее, но работает везде. Если установлен — бот переключится на более быстрый режим webhook.

### 6️⃣ Развертывание

1. Нажмите кнопку **"Развернуть"** или **"Deploy"**
2. Дождитесь завершения деплоя (2-5 минут)
3. Проверьте логи в разделе **"Логи"** — должно появиться:
   ```
   ✅ Телеграм бот запускается...
   BOT_TOKEN: ***xxxx
   OWNER_ID: 123456789
   ```

### 7️⃣ Проверка работы

Отправьте себе сообщение в личный чат боту:
```
.me
```

Если бот ответил, значит всё работает! ✅

## Режимы работы

### 🔄 Polling (по умолчанию)

- Бот сам опрашивает Telegram каждые несколько секунд
- **Преимущества:** простая настройка, работает везде
- **Недостатки:** медленнее, больше нагрузка на сервер

**Когда использовать:** Для тестирования и если у вас нет собственного домена

### 🔗 Webhook

- Telegram сам отправляет обновления вашему боту
- **Преимущества:** быстро, меньше нагрузка
- **Недостатки:** нужен собственный домен/URL

**Когда использовать:** Для продакшена

**Как настроить:**
1. Получите URL вашего приложения в Amvera (например: `https://my-bot.amvera.io`)
2. Установите переменную `WEBHOOK_URL` = `https://my-bot.amvera.io`
3. Перезагрузите приложение

## Переменные окружения в Amvera

Чтобы найти BOT_TOKEN и OWNER_ID:

### BOT_TOKEN
1. Напишите @BotFather в Telegram
2. Отправьте `/newbot`
3. Назовите бота и юзернейм
4. Получите строку вида `123456:ABCdefGHIjkLmNOpQrStUVwxYZ1234567`

### OWNER_ID
1. Напишите @userinfobot в Telegram
2. Вам придёт ваше user ID

## Если что-то не работает

### ❌ Бот не запускается

Проверьте логи в Amvera:
1. Откройте приложение
2. Нажмите **"Логи"**
3. Ищите ошибку

**Частые ошибки:**
- `BOT_TOKEN не установлен` — добавьте переменную BOT_TOKEN
- `OWNER_ID не установлен` — добавьте переменную OWNER_ID
- `Invalid token` — проверьте корректность токена

### ❌ Бот не отвечает на .me команду

- Проверьте, что вы отправляете сообщение именно боту (не в группу)
- Убедитесь, что ваш OWNER_ID указан правильно
- Проверьте, что в сообщении `business_connection_id` установлен (это зависит от Telegram Business API)

### ❌ Ошибка при деплое

- Убедитесь, что все файлы загружены правильно
- Проверьте `runtime.txt` — версия Python должна быть `python-3.11.7` или выше
- Посмотрите логи деплоя в Amvera

## Полезные команды (для локального тестирования)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск бота локально (будет использовать .env файл)
python bot.py

```
