# Telegram Business Secretary Bot

Этот бот слушает входящие сообщения из Telegram Business API и реагирует только на команды `.me` от владельца аккаунта.

## Что делает бот

- Проверяет, что сообщение пришло из личного чата и от владельца аккаунта.
- Если текст сообщения начинается с `.me`:
  - удаляет исходное сообщение через `delete_business_messages`;
  - отправляет ответ в тот же бизнес-чат через `send_message` с `business_connection_id`.
- Ответ содержит визуально смещённый по центру текст: `*ОТВЕТ БЫЛ ЗАЦЕНТРИРОВАН И БЫЛ ТЕКСТ* ВСЕ РАБОТАЕТ`.

## Требования

- Python 3.10+
- Telegram Business API, настроенный в личном аккаунте.
- У бота должно быть разрешение `can_delete_all_messages`.

## Настройка

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
3. Заполните значения:
   - `BOT_TOKEN` — токен бота.
   - `OWNER_ID` — ваш Telegram user_id.
   - `WEBHOOK_URL` — публичный URL, на который Telegram будет отправлять update.
   - `WEBHOOK_PATH` — путь вебхука, например `/webhook`.
   - `PORT` — порт для вебхука (например, 8080).
4. Запустите бота:
   ```bash
   python bot.py
   ```

## Примечание про Amvera

На Amvera можно задать переменные окружения через интерфейс платформы или секреты. Для продакшена лучше не хранить токен прямо в коде и не пушить `.env` в репозиторий.

## Важный момент

Telegram не умеет реально центрировать текст по горизонтали в обычном `sendMessage`. Поэтому для визуального эффекта используются пробелы слева от текста.
